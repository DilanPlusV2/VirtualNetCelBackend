# Simple Node.js API

This is a Node.js API project configured to run using `npm start`.

## Prerequisites

Make sure you have the following installed on your machine:
* [Node.js](https://nodejs.org/) (which includes npm)

## Getting Started

Follow these steps to set up and run the project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DilanPlusV2/VirtualNetCelFrontend.git
   cd VirtualNet-cel_frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the application:**
   ```bash
   npm start
   ```

4. **Access the API:**
   Open your browser or an API client (like Postman or cURL) and navigate to `http://localhost:3000` (or the port specified in your application).
